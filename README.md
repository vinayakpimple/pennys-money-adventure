# Penny’s Money Adventure — 10x picture-book rebuild

Open `index.html`, or run `python3 -m http.server 5180 --directory /workspace/pennys-10x` and visit http://localhost:5180/

Same game systems and `penny-save-v2` save as the original. No accounts, ads, backend, or real money.

Home is a winding-path town (not a card grid). Penny is a watercolor mascot with shop overlays. Bank, shop, kindness, and quest are illustrated rooms.

Juice: coin fly-to-wallet, jar fill, SVG plant stages, confetti, 3D buttons, WebAudio stingers.

Easy-read, mute, and read-to-me (Web Speech) are included. Hash routes and coin rules match the original.

Brand idle/cheer portraits live in `assets/`. Town art is original SVG (no town PNG was available).
